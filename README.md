## How to Edit

### On the Project Platform
Visit the project platform and make changes. They’ll be automatically committed to the repo.

### Locally in Your IDE
Clone the repo, install dependencies, and run the dev server:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm i
npm run dev
```

### Directly in GitHub
Edit files in GitHub and commit your changes.

### GitHub Codespaces
Launch a Codespace from the repo page, make edits, and push changes.
